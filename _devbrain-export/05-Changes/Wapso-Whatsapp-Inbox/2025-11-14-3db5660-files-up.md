- Adds a two-pane inbox that lists Kapso conversations and polls them.
- Send path covers text, image, video, audio, document, templates, and up to three reply buttons.
- Media is proxied through `/api/media/[mediaId]` with `auth: 'never'`.
- The 24-hour window is a check in `message-view.tsx`, not in the send route.
- Kapso client base URL is `https://app.kapso.ai/api/meta/`. Env names: `PHONE_NUMBER_ID`, `KAPSO_API_KEY`, `WABA_ID`.
- No login, no database, no tests, no CI workflow, no office-hours queue.

Risks: every API route is unauthenticated. A public deploy can read chats and send from the business number. The media route logs download sizes.

How tested: not run in this dump. There is no test script. See [[Commands]] and [[Quirks]].
